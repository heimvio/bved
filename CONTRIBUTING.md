# Contributing

Issues and pull requests are welcome — especially corrections where this library and the bved specification disagree, and real-world CSV exports (anonymised) that the presets do not recognise.

- **Spec first.** Field tables (`src/fields.ts`) and code tables (`src/tables/*.json`) are transcriptions of the published specification. Please cite page and field number of the specification in your change.
- **Code tables are JSON.** Edit `src/tables/<X>.json`; `npm run build` regenerates `src/tables/generated.ts`, a test checks they match.
- **Golden files** in `test/golden/` are generated by `scripts/make-golden.py` / `scripts/make-golden-csv.py` from spec positions, independently of the TypeScript code. Change the scripts, not the files.
- **No Node.js APIs in `src/`** — the library must keep working in the browser (`Uint8Array`, no `Buffer`, no `fs`). Tests may use Node.
- **Never put real personal data** (names, addresses, meter readings) into tests or issues.
- `npm test` and `npm run build` must pass.
